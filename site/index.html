    How this works

    Hours come from the Jira time entries (worklogs) each person adds. An entry counts on the day it was logged for, in that person’s time zone. A scheduled GitHub job reads Jira about every 30 minutes on workdays and saves an encrypted copy here, so the page shows the time of the last update. 🔄 Update loads the newest saved copy.

    The data is encrypted with the team password, so only people who know it can read it.
